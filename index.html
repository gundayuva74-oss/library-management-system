Project Specifications

BookNest is engineered as a zero-dependency, single-file Online Library Management System specifically tailored for academic evaluation.

  • Architecture: Single HTML5 File (HTML + CSS in <style> + JS in <script>)
  • Persistence: HTML5 Browser localStorage
  • Fine Policy: $1.00 per overdue calendar day
  • Safety Controls: Prevents negative book copies; forbids deleting books or members tied to active loans; validates due dates.
